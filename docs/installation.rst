Installation
============

Requirements
------------

* Python 3.10 or newer
* `globus-sdk <https://pypi.org/project/globus-sdk/>`_ 4.0+
* `prompt-toolkit <https://pypi.org/project/prompt-toolkit/>`_

From PyPI
---------

.. code-block:: shell

   python3 -m pip install educelab-globus

From source
-----------

.. code-block:: shell

   git clone https://github.com/educelab/educelab-globus.git
   cd educelab-globus
   python3 -m pip install -e '.[dev]'
